# AI Audit Demo Kit

Ce kit contient :

- `specs-claude.md` — cahier des charges détaillé à donner à Claude.
- `mockup.html` — maquette interactive autonome.
- `demo-data/` — 3 entreprises fictives cohérentes avec documents, CSV, emails et ground truth.

## Entreprises
1. AtlasPro Distribution — distribution B2B.
2. Darna Facility Services — maintenance multi-sites.
3. MaghrebPack Industries — industrie.

Chaque entreprise contient des problèmes volontairement injectés pour tester le moteur d'audit.

## Usage conseillé
1. Ouvrir `mockup.html` dans un navigateur.
2. Donner `specs-claude.md` à Claude avec le dossier `demo-data`.
3. Demander à Claude d'implémenter le produit par étapes dans l'ordre indiqué dans le cahier des charges.
